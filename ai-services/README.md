## 🛰️ Neural Architecture

SwiftChat is not just a social network; it is a **Sentient Prism** — a platform where human interaction is enhanced by a distributed grid of specialized AI microservices.

### 🧠 4-Tier Intelligence Fallback

Our core assistant, **ARIA**, operates on a high-availability fallback loop:

1. **Llama-4 (Maverick 17B)** – Primary reasoning engine  
2. **DeepSeek V3** – Secondary analytical node  
3. **Mistral Small 3.1** – Fast response generator  
4. **IBM Granite 3.3** – Stability fallback  

### 👁️ Multimodal Vision Pipeline

Powered by **Gemma-3**, SwiftChat performs deep-frame analysis on shared media.

### 🕵️ Semantic Vector Search

Using **NVIDIA Nemoretriever** + **Atlas Vector Search**, users can search by *vibes & emotions*.

## 🚀 Deployment

### 1. Setup Environment

Create `.env` file:

# Core Metrics
NVIDIA_API_KEY=your_key_here
MONGODB_URI=mongodb://root:example@mongodb:27017/swiftchat?authSource=admin
REDIS_HOST=redis
JWT_SECRET=your_secret_vibe

### 2. Run Project

docker-compose up --build -d

### 3. Access

- Frontend: http://localhost  
- API Docs: http://localhost/api-docs/  
- AI Health: http://localhost:8004/health
